# Media

All photos and video come from the Haras La Alhambra media folder on Google Drive, cropped and compressed to WebP (video: H.264 MP4, faststart, no audio). Keep each image ≲300 KB.

Crops are chosen so the whole horse and rider stay visible on desktop and phones. Where a frame has a fixed shape, the file is pre-cropped to that shape:

| File | Where | Source | Shape |
| --- | --- | --- | --- |

| `origen.webp` | Chapter I arch | `facility-paddock-palms` | 4:5 |
| `arabe.webp`, `pre.webp`, `hispano.webp` | Bloodline panels | `breeding-black-stallion`, `hero-main`, `ig-champion` | 4:3 |
