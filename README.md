# Haras La Alhambra

Website for Haras La Alhambra: Arabian and Pura Raza Española breeders in Santa Cruz de la Sierra, Bolivia, since 1993.

Static site built with Vite, GSAP (ScrollTrigger, SplitText) and Lenis. Spanish by default, English via the ES/EN toggle.

```bash
npm install
npm run dev      # local dev server
npm run build    # production build in dist/
```

- Copy: `index.html` (Spanish) and `src/i18n.js` (English)
- Animations: `src/main.js`
- Styles: `src/style.css`
- Photos and videos: `public/media/` (see its README for file names)
